RRP/1 · TLS 1.3 · minSdk 14 · zero third-party SDK

ReverseRay — прокси, выходящий через ваше Android-устройство

Исходящий трафик идёт с IP вашего устройства — домашней или мобильной сети. Go-сервер на VPS принимает SOCKS5/HTTP и проталкивает его через RRP/1-туннель на Android-клиент, который сам диалит цель. NAT и серый IP больше не проблема: соединение инициирует телефон.

GitHub → Quickstart за 5 минут 

┌────────────────┐   SOCKS5/HTTP   ┌────────────────────┐    RRP/1 (TLS 1.3)    ┌──────────────────┐
│ браузер / софт │ ──────────────► │   VPS: Go-сервер   │ ◄───────────────────► │ телефон: egress  │
│  curl, tor, …  │   :1080 / :8080 │  auth · rate-limit │   исходящее с         │ диалит цель,     │
│                │                 │  анти-DDoS         │   телефона (NAT ok)   │ мобильный IP     │
└────────────────┘                 └────────────────────┘                       └──────────────────┘

🌐 Egress = IP устройства

Цель видит телефон, сервер видит только туннель. Домашний Wi-Fi, LTE, чужой город — выходная точка всегда в твоём кармане.

🛡 Безопасно по умолчанию

TLS 1.3 на BouncyCastle, SPKI-pin, ALPN reverseray/1, anti-SSRF guard (приватные диапазоны закрыты), flow-control 512 КБ на стрим.

🪶 Лёгкий APK

minSdk 14, universal APK, ноль сторонних SDK кроме BC и zxing (QR-enrollment). Foreground-сервис, автостарт, reconnect с backoff.

Quickstart — 5 минут

  1. Сервер (VPS): 
    git clone https://github.com/stelgen/reverseray && cd reverseray
docker compose up -d reverse-proxy          # SOCKS5 :1080, HTTP :8080
docker compose exec reverse-proxy ./reverseray enroll --name Home
# → rrp://token@vps.example:443,8443/?pin=BASE64SPKI&name=Home
  2. Телефон: собери APK и вставь rrp://-строку (или отсканируй QR): 
    ./gradlew :app:assembleRelease   # env: RR_KEYSTORE, RR_KEY_ALIAS, RR_KEYSTORE_PASSWORD
  3. Проверка: 
    curl --socks5 vps.example:1080 https://ifconfig.me   # в ответе — IP устройства
