ReverseRay

Твой телефон = твой VPN. Сервер — просто дверь, интернет — с твоего SIM.

[Приложения] → [Xray: socks5] → [Docker: reverseray]
                                    │ TLS 1.3 RRP/1 (телефон диалит сам)
                                    ▼
                              [Android APK] → 🌍 (резидентный IP)
GitHub →

🔓 Без VPS-провайдера

Egress — твой телефон: домашний Wi-Fi или мобильный оператор. Резидентный IP, никакого хостинг-ASN в whois.

🛡️ Zero-trust транспорт

TLS 1.3 + SPKI-pin на CA, HMAC-токены с одноразовым nonce, анти-replay. Сервер хранит только хэши токенов.

📵 Работает за CGNAT

Телефон сам инициирует соединение. Входящие порты не нужны — ни на телефоне, ни в сети оператора.

Quickstart — 5 минут

mkdir -p state && chown 65532:65532 state
docker compose up -d
docker compose exec reverseray /reverseray enroll \
  -state-dir /var/lib/reverseray -name phone-1 -host YOUR_IP -port 443
# → вставь конфиг-строку rrp://… в приложение
curl --proxy socks5h://127.0.0.1:1080 https://ifconfig.me   # → IP телефона
